# Рюкзак полигона «Между парами»

Материалы для отчёта от 13 ноября 2026 года. Рюкзак открывается по I. Учебник и набор восстановления получили пиксельные иконки, ячейки и карточку выбранного предмета. Карточка показывает эффект до применения. Наборы отображаются одной ячейкой со счётчиком. После применения игрок видит результат в открытом рюкзаке.

Три теста PlayMode прошли. Маршрут через кнопки проверяет открытие по I, чтение учебника, применение набора, обновление счётчика и защиту от повторного расхода. [Результаты Unity Test Framework](checks/playmode.csv)

После настройки переноса строк пересобран Windows Player. Пять кадров проверены при 1280×720 и 1024×576. Состояния рюкзака подготовлены сценарием захвата через RenderTexture. [Выписка из логов сборки и захвата](checks/build-and-captures.txt)
