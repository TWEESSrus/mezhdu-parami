# Состояние разработки Между парами

Обновлено 6 ноября 2026 года. Это краткий снимок текущего состояния, а не журнал всей переписки. Обновлять после каждого законченного рабочего шага.

## Контекст

- Игра: одиночный 2D симулятор студента с RPG и стратегическим управлением временем, деньгами и энергией.
- Первая игра: весь первый курс; зимняя сессия посередине, летняя сессия и эпилог в конце. Не выпускной курс.
- Объём: 12 ключевых дней × 3 периода; 3 зоны, 4 NPC, около 14 событий. Точные правила — Game_Design.md 0.3.
- Статы: интеллект, сила, харизма; здоровье общее. Без психических подшкал и одежды с характеристиками.
- Команда: пользователь — код и системы; товарищ — графика, звук, окружение, квесты и тестирование; геймдизайн совместный.
- Бюджет: по 80 часов двух разработчиков. Готовые материалы и ИИ помогают, но результат проверяем в Unity и сборке.

## Ограничения и проверки

- Срез содержит 3 дня, а не весь курс. Сжатые даты консультации (1) и обещания (3) не меняют Game_Design.md: в полном календаре это дни 4 и 8. Допуск к разовой смене пока упрощён.
- Нет полного календаря года, жилья, магазина и предметов, силы и харизмы в прогрессии, экзаменов, переноса и подмены обещания, остальных NPC, звука и сохранений. Еда пока выбирается только между днями; развитой системы питания и лечения нет.
- SashaQuestDefinition и три ActivityDefinition лежат в Data/: ID sasha.prototype.promise, sasha.consultation, sasha.help, work.special. Изменяемое состояние хранится в SashaPromise, не в общем ассете. PrototypeDay содержит календарь среза; UI согласует действие и проверку срока. Это одна цепочка, не универсальный движок событий.
- Карта — одна иллюстрация. У неё нет отдельных слоёв перекрытия и полной детализации коллизий вне маршрута. Для обоих вариантов героя используется одна анимация; Саша пока обозначен временным спрайтом. `tilemap_future.png` — эскиз, остался в исходном коммите.
- Перед изменениями смотреть git status; не перезаписывать чужие изменения.
- Unity CLI обновлён до 1.0.0-beta.17. При закрытом редакторе работают `unity run Unity -- -executeMethod ...` и `unity test Unity --mode EditMode/PlayMode`; прямой запуск Editor -batchmode ранее не получал лицензию. Для открытого редактора использовать `unity command` с --project-path, --caller plugin и --skill. Не запускать второй Editor для того же проекта.
- `InterfaceRefresh.Apply` меняет существующий UI через Unity API, сохраняет обработчики; не пересоздаёт игровой мир. Повторное применение возвращает размеры и цвета к макету из кода. После ручной правки UI сначала согласовать изменения с этим кодом.
- Не читать весь геймдизайн автоматически: открывать только нужный раздел. Проверенные результаты и точные следующие шаги обновлять здесь.
